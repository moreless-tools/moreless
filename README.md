# MORELESS

Edit a PDF, prepare a batch of images or work through a JSON file in MORELESS. The editors share their controls, and the command palette finds the action that matches your task or file.

**[Open MORELESS](https://moreless.tools/en/)** · [Try the sample files](examples/) · [Product guides](https://moreless.tools/en/docs/) · [Feedback](https://moreless.tools/en/feedback/)

## What you can work on

| Area | In the web product |
| --- | --- |
| [PDF documents](https://moreless.tools/en/tools/pdf-editor/) | Edit supported text, organize pages, merge and split files, annotate, fill forms and place visible signatures. Compare PDFs, redact content, add page numbers or watermarks, and prepare files for sharing. |
| [Images](https://moreless.tools/en/tools/image-converter/) | Convert formats including HEIC, resize and crop batches, and add watermarks. Use [Color Studio](https://moreless.tools/en/tools/color-studio/) for palettes, gradients and contrast checks. |
| [JSON and data](https://moreless.tools/en/tools/json-formatter/) | Format, repair, compare and query JSON. Validate schemas, generate TypeScript interfaces and convert between data formats. |
| [Text](https://moreless.tools/en/tools/word-counter/) | Compare revisions, count words, change case and check duplicate words. Draft and export notes in the [notepad](https://moreless.tools/en/tools/online-notepad/). |
| [QR codes](https://moreless.tools/en/tools/qr-code-generator/) and [barcodes](https://moreless.tools/en/tools/barcode-generator/) | Create codes for links, Wi-Fi or contact details. Import batches from CSV and export label sheets. |
| [Code](https://moreless.tools/en/tools/code-editor/) | Edit HTML, CSS and JavaScript with a live preview. Encode and decode Base64, generate hashes and create UUIDs. |

The command palette also handles calculations, equations and unit or currency conversions as you type.

We develop our own PDF processing technology alongside the product. Office conversions and OCR are in **beta**. Review converted files before using or sharing them.

## Across platforms

MORELESS is developed by **MORELESS s.r.o. in Prague**. We want the steps between opening a file and finishing a task to work together across the applications people use at work.

The web product is available now. **MORELESS for Mac is in development**, with public interface demos and an alpha waitlist. We plan to add more platforms and integrations.

[See MORELESS for Mac](https://moreless.tools/en/app/mac/) · [Web changelog](https://moreless.tools/en/changelog/web/)

## Using the web product

PDF, document, image and text processing runs on your device. Optional usage analytics require consent. See the [privacy policy](https://moreless.tools/en/privacy-policy/) for details.

The current web product is free for personal and commercial work and does not require a MORELESS account. Favorites, presets and notepad drafts stay in the same browser. Export anything you want to keep before clearing browser data.
