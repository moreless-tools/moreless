# Review a PDF and fill its approval form

Download [project-brief.pdf](../examples/project-brief.pdf) and open it in the [MORELESS PDF editor](https://moreless.tools/en/tools/pdf-editor/). The sample has three pages and contains fictional project information.

Use the page previews to inspect the brief, checklist and approval form. Try adding an annotation to the brief, then fill the reviewer, review date and reference fields on the last page. Select the approval checkbox if you want to test it.

Export the PDF and reopen the exported file. Check that the annotation and form values are present. Keep the original sample so you can try page reordering or splitting in a separate copy.

This is an interactive PDF form. A visible signature placed in the editor is a mark on the page and should not be treated as a certificate-based digital signature.
